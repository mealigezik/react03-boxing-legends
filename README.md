# Boxing Legends

A React learning project presenting searchable boxing profiles. Player cards can switch between an image and a local list of statistics.

## Tech stack

- React 18
- JavaScript
- React-Bootstrap
- CSS

## Run locally

```bash
npm install
npm start
```

## Data and limitations

The data is stored locally in `src/helpers/data.js`; this is not a live sports-data service. Verify statistics and image-use rights before redistribution.

## Validation

Automated tests have not yet been added. The following commands can be used when the corresponding scripts are configured:

```bash
npm test
npm run build
```
